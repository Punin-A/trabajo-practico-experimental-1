# 🌱 Raíz Urbana

Formulario web de postulación para un programa de apadrinamiento y cuidado de árboles urbanos. Este proyecto académico aplica los fundamentos de **HTML5, CSS3 y JavaScript** para crear una interfaz interactiva, responsiva y con validaciones personalizadas.

## Características

* Formulario con campos para nombre, correo electrónico, edad, teléfono, espacio de cuidado y contraseña.
* Validación de campos obligatorios y formatos de datos.
* Validación de edad entre 18 y 90 años y teléfono de 10 dígitos.
* Validación de contraseña con un mínimo de 8 caracteres, una letra y un número.
* Mensajes de error y confirmación.
* Opción para mostrar u ocultar la contraseña.
* Indicador visual de fortaleza de la contraseña.
* Diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías utilizadas

* **HTML5:** estructura del formulario y contenido de la página.
* **CSS3:** diseño visual, distribución de elementos y adaptación a diferentes pantallas.
* **JavaScript:** validaciones, eventos y manipulación del DOM.

## Instalación y ejecución

1. Clona el repositorio o descarga el proyecto.
2. Abre la carpeta en Visual Studio Code o en tu editor de código preferido.
3. Abre el archivo `index.html` en un navegador web.
4. Completa el formulario para probar sus funcionalidades.

No requiere instalaciones adicionales ni un servidor backend.

## Consideraciones

Este proyecto es una demostración académica. Las validaciones se realizan en el navegador y los datos no se envían a un servidor ni se almacenan de forma persistente.
